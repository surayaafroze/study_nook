## 🚀 About StudyNook

StudyNook is a modern study room booking platform where students and library users can discover, book, and manage study rooms with ease. Users can add their own study rooms, manage listings, and make bookings through a secure and user-friendly interface.

---

## ✨ Features

- 🔐 Secure Authentication with JWT and HTTP-only Cookies
- 📚 Browse and Search Available Study Rooms
- 🏢 Add, Update, and Delete Your Own Room Listings
- 📅 Real-Time Room Booking System
- 🚫 Booking Conflict Detection to Prevent Double Bookings
- 🔍 Search Rooms by Name and Filter by Amenities
- 👤 Personal Dashboard for Managing Listings and Bookings
- 📱 Fully Responsive for Mobile, Tablet, and Desktop
- 🔔 Beautiful Toast Notifications
- ⚡ Fast and Optimized User Experience

## ⚙️ Installation

### Clone Repository

```bash
git clone YOUR_CLIENT_REPOSITORY_LINK
```

### Install Dependencies

```bash
npm install
```

### Create Environment File

```env
NEXT_PUBLIC_API_URL=YOUR_SERVER_URL
```

### Run Development Server

```bash
npm run dev
```
